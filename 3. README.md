# 4-to-2 Encoder using Verilog

## Overview
This project implements a 4-to-2 Encoder in Verilog HDL.

## Truth Table

| Input | Output |
|-------|--------|
|0001|00|
|0010|01|
|0100|10|
|1000|11|

## Files

- encoder.v → Verilog design
- encoder_tb.v → Testbench
- simulation_output.png → Simulation waveform
- README.md → Documentation

## Simulation

Compile:
```
iverilog -o encoder encoder.v encoder_tb.v
```

Run:
```
vvp encoder
```

View Waveform:
```
gtkwave encoder.vcd
```

## Expected Output

```
Input = 0001 Output = 00
Input = 0010 Output = 01
Input = 0100 Output = 10
Input = 1000 Output = 11
```
